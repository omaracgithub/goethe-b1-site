Goethe B1 Exam Format: Complete Guide

June 10, 2026·Goethe B1

Key takeaways

  • Goethe B1 certifies CEFR B1 (intermediate).
  • Four modules: Lesen, Hören, Schreiben, and Sprechen — each scored 0–100.
  • The exam is modular: pass each module separately with ≥60/100.
  • Typical duration: ~2 h 45 min written + ~15 min speaking.

Preparing for Goethe B1? This guide on b1.goetheprep.com explains the official B1 structure. The certificate is widely used for German citizenship and residency, vocational training, and many jobs.

What the B1 exam tests

  • Lesen (Reading): 65 min, 5 parts — matching, multiple choice, and gap-fill.
  • Hören (Listening): ~40 min, 4 parts — announcements, conversations, interviews.
  • Schreiben (Writing): 60 min, 3 parts — informal message, forum post, formal message.
  • Sprechen (Speaking): ~15 min, 3 parts — planning together, presentation, discussion (paired).

Scoring

Each module is scored from 0 to 100, and you need 60 points to pass it. B1 is modular, so you can sit and pass each module separately and retake only the one you fail. See our passing score guide.
